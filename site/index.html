Each month's map pools new listings from the past year (weighted toward recent months and adjusted for citywide price changes), counting each listing once when it first appears. Prices are a weighted average of nearby listings, using the smallest radius with enough data. Sizes differ by a fixed multiplier estimated from listings at the same locations. Click anywhere for the estimate at that spot.

Zillow's layer is its rent index for each ZIP code, covering houses, condos and apartments of every size together, so it isn't comparable dollar for dollar with the rent map. Each ZIP code is colored whole, drawn from Census approximations of postal boundaries. "Relative to the city" compares with the typical home across these ZIP codes.

StreetEasy's dots are its median asking rents. They follow the month, size and view chosen above, using its latest month where the map's is newer. StreetEasy doesn't publish its neighborhood boundaries, so each dot only marks roughly where the neighborhood is. Its largest size is 3BR+. A faded dot had fewer than listings of that size, and shows a 3-month average weighted by listings. "Relative to the city" compares with StreetEasy's citywide median.
