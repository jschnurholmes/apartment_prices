Boston rent trends

From monthly scrapes of Padmapper listings since 2013, the same data behind the rent map.

Typical rent

The listings estimate is the median over every home in the area (2020 Census housing units) of the local estimate at that home, so a month with unusually many listings in pricey areas doesn't read as a price rise. It sits below the listing medians because listings are concentrated in pricier neighborhoods. The two medians are raw: listings that are new that month, and everything on the market. The last runs high because overpriced units stay listed longer.

Size premium at the same location

Rent of each size relative to a 2BR on the same block, estimated jointly with the listings estimate.

Listings per month

Everything listed at the time of each scrape, and the listings that were new that month (counting a relisted unit only once). Short scrapes and gaps in the record show up as dips.

By neighborhood

Listings estimate averaged over homes within 300m of each spot, on a shared scale, sorted by the latest value. Gaps are months without enough nearby data.

Longer history from StreetEasy

StreetEasy's own listings, separate from the listings. Like the listing medians above, its medians describe what's listed, which concentrates in pricier neighborhoods, so they run above the listings estimate. Data Provided by Zillow Group.

Rent index

StreetEasy's rent index follows the same homes from one listing to the next, so a change in what happens to be listed doesn't read as a change in rent. It covers all sizes together.
